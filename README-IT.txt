Upload every file and folder to the repository root. Enable GitHub Pages from main/root. The admin page needs a fine-grained token for the repository with Contents: Read and write.

Status rules:
- Scheduled: displayed in category schedule only.
- In progress: displayed in live.html with category and field.
- Completed: used for standings.

Final qualification replacement occurs only when every qualification game in each relevant group is Completed.
Tie order: winning percentage, head-to-head when exactly two teams are tied, manual TQB, run differential, runs scored. TQB is entered in the administration page.
